# Riyadh-Water-Tanker

موقع مؤسسة الباهي للمياه بالرياض — وايت ماء توصيل لجميع أحياء الرياض.

## SEO و النشر

- تم إعداد الموقع وفق أفضل ممارسات SEO:
  - **Meta:** title فريد، description، keywords، robots، author، canonical على كل صفحة.
  - **اجتماعي:** Open Graph و Twitter Card مع أبعاد الصورة (1200×630)، theme-color، geo.region (SA-01).
  - **البيانات المنظمة:** LocalBusiness + ContactPoint + WebSite على الرئيسية؛ AboutPage، ContactPage، BreadcrumbList على الصفحات الداخلية.
  - **تقني:** sitemap.xml، robots.txt، رابط تخطي للمحتوى (skip link)، aria-current و aria-label حيث يلزم.
  - **صور:** نصوص alt وصفية ومنطقية لجميع الصور.
- **قبل النشر على دومينك:** استبدل `https://www.riyadhwater.com` بدومينك الفعلي في جميع ملفات HTML و `sitemap.xml` و `robots.txt`.
